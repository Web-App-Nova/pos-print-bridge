# POS Printer Agent (pos-print-bridge)

<p align="center">
  <img src="assets/logo.png" alt="WEBAPPNOVA logo" height="96"/>
</p>

Local **Printer Agent** for POS billing PCs (Windows & macOS). Install once on each billing machine; the agent starts automatically after login/restart and exposes a localhost HTTP API for printer discovery and raw ESC/POS printing.

The POS web app (`pos-billing`) talks to the agent at `http://127.0.0.1:9247`. This repository is **API-only** — there is no React dashboard here; printer configuration UI remains in the POS app.

```text
POS (browser)
     ↓  http://127.0.0.1:9247
Printer Agent (Windows Service / launchd)
     ↓
Thermal printers (USB / LAN)
```

## Architecture

```text
Operating System
       │
       ▼
Printer Agent Service (bundled Node binary)
       ├── Local HTTP API (127.0.0.1 only by default)
       ├── Printer discovery (USB + system queues + LAN scan)
       ├── In-app print job queue + retry
       ├── ESC/POS passthrough (TCP 9100, CUPS, Windows spooler)
       ├── Persistent configuration
       └── Rotating logs
```

**Important:** ESC/POS bytes are generated by the POS app and sent as `text` or `data_base64`. This agent delivers them to printers; it does not redesign receipt layouts.

## Requirements

### Development

- Node.js 18+

### Production (customer PC)

- Windows 10/11 x64 **or** macOS (Apple Silicon / Intel)
- Billing PC on the same LAN as network printers (for LAN discovery)
- No separate Node.js install required when using the packaged installer

## Windows installation

### Prerequisites for building the Setup.exe

1. `npm run package:windows`
2. Download [NSSM](https://nssm.cc/download) and place `win64/nssm.exe` at `installer/windows/vendor/nssm.exe`
3. Install [Inno Setup 6](https://jrsoftware.org/isinfo.php)
4. Run:

```powershell
powershell -ExecutionPolicy Bypass -File installer\windows\build-installer.ps1
```

### Customer install (Windows)

The customer PC does **not** need this repo, npm, or Node.js.

1. Copy `POS-Printer-Agent-Setup.exe` to the billing PC
2. Double-click and follow the wizard (accept the WEBAPPNOVA LLP license)
3. Installer will:
   - Install files under `C:\Program Files\POS Printer Agent\`
   - Create data/log folders under `%PROGRAMDATA%\POS Print Bridge\`
   - Register Windows Service **`POSPrintBridge`** (auto-start)
   - Start the service and health-check `http://127.0.0.1:9247/health`
4. After reboot / login, the agent starts automatically

### Verify install (Windows)

```powershell
# Service running?
Get-Service POSPrintBridge

# API healthy?
Invoke-WebRequest http://127.0.0.1:9247/health | Select-Object -ExpandProperty Content

# Or open in browser:
# http://127.0.0.1:9247/health
# http://127.0.0.1:9247/
```

Expected: JSON with `"status":"running"`.

### Service management (Windows)

```powershell
# Status
Get-Service POSPrintBridge

# Stop / start / restart
Stop-Service POSPrintBridge
Start-Service POSPrintBridge
Restart-Service POSPrintBridge

# Logs
explorer "$env:ProgramData\POS Print Bridge\logs"
```

NSSM is used for auto-restart on crash.

### Uninstall (Windows)

**Option A — Settings (recommended for customers)**

1. Open **Settings → Apps → Installed apps** (or **Add or Remove Programs**)
2. Find **POS Printer Agent**
3. Click **Uninstall** and confirm

This stops/removes the `POSPrintBridge` service and deletes application files.

**Option B — PowerShell (manual)**

```powershell
# Stop + remove Windows Service
$InstallDir = "${env:ProgramFiles}\POS Printer Agent"
$Nssm = Join-Path $InstallDir "nssm.exe"
if (Test-Path $Nssm) {
  & $Nssm stop POSPrintBridge confirm
  & $Nssm remove POSPrintBridge confirm
} else {
  Stop-Service POSPrintBridge -Force -ErrorAction SilentlyContinue
  sc.exe delete POSPrintBridge
}

# Remove app files
Remove-Item -Recurse -Force $InstallDir -ErrorAction SilentlyContinue

# Optional: also remove config + logs
Remove-Item -Recurse -Force "$env:ProgramData\POS Print Bridge" -ErrorAction SilentlyContinue
```

**Verify uninstall (Windows)**

```powershell
Get-Service POSPrintBridge -ErrorAction SilentlyContinue
# Should print nothing / not found

Invoke-WebRequest http://127.0.0.1:9247/health -ErrorAction SilentlyContinue
# Should fail (connection refused)
```

> Note: config/logs under `%PROGRAMDATA%\POS Print Bridge\` may remain after Option A unless deleted manually (see Option B).

## macOS installation

### Build the .pkg (on a Mac)

```bash
npm run package:macos
npm run release:macos
# or: bash installer/macos/build-pkg.sh
```

### Customer install (macOS)

The customer Mac does **not** need this repo, npm, or Node.js.

1. Copy `POS-Printer-Agent.pkg` to the billing Mac
2. Double-click the `.pkg` and follow the installer
3. Installer will:
   - Install files under `/usr/local/lib/pos-print-bridge/`
   - Create wrapper `/usr/local/bin/pos-print-bridge`
   - Register LaunchAgent `com.pos.print-bridge` (`RunAtLoad` + `KeepAlive`)
   - Create config/log folders for the user
   - Start the agent and verify `http://127.0.0.1:9247/health`
4. After login / restart, the agent starts automatically

### Verify install (macOS)

```bash
# LaunchAgent running?
launchctl print "gui/$(id -u)/com.pos.print-bridge" | grep "state ="

# API healthy?
curl http://127.0.0.1:9247/health

# Files installed?
ls /usr/local/lib/pos-print-bridge/pos-print-bridge
ls ~/Library/LaunchAgents/com.pos.print-bridge.plist
```

Or open in browser:

- http://127.0.0.1:9247/health  
- http://127.0.0.1:9247/  

Expected: JSON / status page with agent **Running**.

### Service management (macOS)

```bash
# Status
launchctl print "gui/$(id -u)/com.pos.print-bridge"

# Restart
launchctl kickstart -k "gui/$(id -u)/com.pos.print-bridge"

# Stop (until next login / manual start)
launchctl bootout "gui/$(id -u)/com.pos.print-bridge"

# Logs
tail -50 ~/Library/Logs/pos-print-bridge/agent.log
tail -50 ~/Library/Logs/pos-print-bridge/out.log
tail -50 ~/Library/Logs/pos-print-bridge/err.log
```

### Uninstall (macOS)

**Option A — Uninstall script (recommended)**

Open **Terminal** and run:

```bash
bash /usr/local/lib/pos-print-bridge/uninstall.sh
```

This will:

1. Stop the LaunchAgent  
2. Remove auto-start (`~/Library/LaunchAgents/com.pos.print-bridge.plist`)  
3. Delete app files (`/usr/local/lib/pos-print-bridge`, `/usr/local/bin/pos-print-bridge`)

To also delete config + logs:

```bash
bash /usr/local/lib/pos-print-bridge/uninstall.sh --purge
```

Enter the Mac password if asked (`sudo`).

From a source checkout (developers):

```bash
bash installer/macos/uninstall.sh
bash installer/macos/uninstall.sh --purge
```

**Option B — Manual uninstall**

```bash
# 1) Stop the agent
launchctl bootout "gui/$(id -u)/com.pos.print-bridge"

# 2) Remove auto-start
rm -f ~/Library/LaunchAgents/com.pos.print-bridge.plist

# 3) Remove installed files
sudo rm -rf /usr/local/lib/pos-print-bridge
sudo rm -f /usr/local/bin/pos-print-bridge

# 4) Optional: remove config + logs
rm -rf ~/Library/Application\ Support/pos-print-bridge
rm -rf ~/Library/Logs/pos-print-bridge

# 5) Optional: forget package receipt
sudo pkgutil --forget com.pos.print-bridge
```

**Verify uninstall (macOS)**

```bash
curl http://127.0.0.1:9247/health
# Should fail (connection refused)

ls /usr/local/lib/pos-print-bridge
# Should say: No such file or directory

launchctl print "gui/$(id -u)/com.pos.print-bridge"
# Should say service not found / error
```

## API documentation

Base URL: `http://127.0.0.1:9247`  
Bind address is localhost by default (`POS_PRINT_BRIDGE_HOST`). Do not expose on `0.0.0.0` unless you explicitly intend LAN access.

### Health & version

| Method | Path | Description |
|--------|------|-------------|
| GET | `/health` | `{ status, version, uptime, ... }` |
| GET | `/version` | `{ version }` |
| GET | `/status` | Legacy POS health (compatible) |

### Discovery & printers

| Method | Path | Description |
|--------|------|-------------|
| GET | `/discover` | USB + system + LAN printers (POS-compatible) |
| GET | `/printers` | Normalized printer list |
| POST | `/printers/discover` | Trigger discovery |
| GET | `/printers/:id` | One printer |
| GET | `/printers/:id/status` | Online/offline/paused |
| POST | `/printers/:id/test-print` | Send a short test slip |

### Printing (POS-compatible)

| Method | Path | Description |
|--------|------|-------------|
| POST | `/print` | Print and wait for confirmation (sync) |
| POST | `/print/kot` | Same as `/print`, jobType=`kot` |
| POST | `/print/bill` | Same as `/print`, jobType=`bill` |

`POST /print` body examples:

```json
{ "host": "192.168.1.50", "port": 9100, "text": "Hello KOT\n\n\n" }
```

```json
{
  "queue": "GP-C80250I_Plus",
  "connection_type": "usb",
  "data_base64": "G0hlbGxvCg=="
}
```

Success includes `printed: true`. Failure (offline/timeout) returns HTTP 422 with `printed: false`.

### OS spooler queues (legacy)

| Method | Path | Description |
|--------|------|-------------|
| GET | `/queues` | System queues + pending OS jobs |
| GET | `/queues/:name` | One queue |
| GET | `/queues/:name/jobs` | Jobs in OS queue |
| DELETE | `/queues/:name/jobs/:jobId` | Cancel OS job |

### In-app job queue

| Method | Path | Description |
|--------|------|-------------|
| GET | `/jobs` | Agent job history |
| GET | `/jobs/:id` | One job |
| POST | `/jobs/:id/retry` | Retry a failed job |
| POST | `/jobs/:id/cancel` | Cancel a queued job |

Job statuses: `QUEUED` → `PRINTING` → `COMPLETED`, or `FAILED` → retry → …

### Auth (optional)

If `config.json` has a non-empty `authToken`, protected routes require:

```http
Authorization: Bearer <token>
```

`/health`, `/status`, and `/version` remain open so the POS can detect online/offline. Auth is **off by default** for POS compatibility.

## Configuration

Config file (created automatically):

| OS | Path |
|----|------|
| macOS | `~/Library/Application Support/pos-print-bridge/config.json` |
| Windows | `%PROGRAMDATA%\POS Print Bridge\config.json` |

Example:

```json
{
  "version": 1,
  "environment": "production",
  "host": "127.0.0.1",
  "port": 9247,
  "authToken": "",
  "printers": [],
  "updateChannel": "stable",
  "updateUrl": "",
  "maxRetries": 2,
  "retryDelayMs": 1500
}
```

### Environment variables

| Variable | Default | Description |
|----------|---------|-------------|
| `POS_PRINT_BRIDGE_ENV` | `development` / `production` | Environment name |
| `POS_PRINT_BRIDGE_PORT` | `9247` | Local HTTP port |
| `POS_PRINT_BRIDGE_HOST` | `127.0.0.1` | Bind address |
| `POS_PRINT_BRIDGE_DATA_DIR` | (platform default) | Config / jobs directory |
| `POS_PRINT_BRIDGE_LOG_DIR` | (platform default) | Log directory |
| `POS_PRINT_TIMEOUT_MS` | `8000` | Submit / TCP timeout |
| `POS_PRINT_CONFIRM_TIMEOUT_MS` | `8000` | Wait for OS job to leave queue |
| `POS_PRINT_CONFIRM_POLL_MS` | `300` | Queue poll interval |
| `POS_DISCOVERY_TIMEOUT_MS` | `220` | Per-host probe timeout |
| `POS_PRINT_BRIDGE_MAX_RETRIES` | `2` | In-app retry count |
| `POS_PRINT_BRIDGE_RETRY_DELAY_MS` | `1500` | Retry backoff |

## Log locations

| OS | Paths |
|----|--------|
| macOS | `~/Library/Logs/pos-print-bridge/agent.log`, `out.log`, `err.log` |
| Windows | `%PROGRAMDATA%\POS Print Bridge\logs\agent.log`, `service-stdout.log`, `service-stderr.log` |

Logs rotate at ~5 MB (keeps 5 rotated files). Typical lines:

```text
2026-08-08 12:00:01 INFO  Printer Agent started
2026-08-08 12:00:02 INFO  Discovered 3 printers
2026-08-08 12:00:05 INFO  Print job created
2026-08-08 12:00:07 INFO  Print job completed
```

## Troubleshooting

| Symptom | Check |
|---------|--------|
| POS says bridge offline | `curl http://127.0.0.1:9247/health` — start service / LaunchAgent |
| USB blank pages on Mac | Agent uses CUPS USB backend for raw ESC/POS; re-select USB queue in POS |
| LAN printer not found | Same subnet; port 9100 open; run `GET /discover` |
| Print returns 422 | Printer offline/paused; see `printer_state` and agent logs |
| Port in use | Change `POS_PRINT_BRIDGE_PORT` / config `port` (update POS env too) |
| Service crash loop | Inspect Windows/macOS logs; ensure binary + `scripts/` are intact |

## Future auto-update

`config.json` includes `updateChannel` and `updateUrl` placeholders. A later updater can:

1. Check latest version  
2. Download a new binary / installer  
3. Replace files  
4. Restart the Windows Service / launchd job  

No automatic updater is implemented in this release.
